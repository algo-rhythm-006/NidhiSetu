# PRAMAAN-AI · System Architecture & Integration Guide

> **Target Audience**: Java Spring Boot Backend Engineers & React Frontend Engineers  
> **Service**: PRAMAAN-AI Python FastAPI Microservice (`ai-service`)  
> **Protocol**: Synchronous HTTP/REST over JSON & Multipart Form-Data  
> **Base URL**: `http://<ai-service-host>:8000` (Local: `http://localhost:8000`)

---

## 1. System Integration Overview

The PRAMAAN-AI system operates as a zero-trust, air-gapped financial security processor. The Java Spring Boot application serves as the primary system orchestrator, handling state transitions, PostgreSQL database operations, institutional user identity, and document storage. 

When a Fixed Deposit Receipt (FDR) is uploaded or an administrative search is requested, the Java backend invokes this Python AI microservice synchronously:

```
┌────────────────────────┐         REST / Multipart        ┌─────────────────────────┐
│                        │────────────────────────────────▶│                         │
│   Java Spring Boot     │   Headers: X-Internal-Token     │   Python FastAPI        │
│   Primary Backend      │                                 │   AI Microservice       │
│   (Port 8080)          │◀────────────────────────────────│   (Port 8000)           │
└────────────────────────┘          Structured JSON        └─────────────────────────┘
            │                                                           │
            ▼                                                           ▼
   PostgreSQL Database                                         RTX 2050 (4 GB VRAM)
   (Persistence & Audit)                                      Qwen2.5-VL / Llama 3.2
```

## 2. Core Integration Rules for Java Developers

### 2.1 Security & Authentication (`X-Internal-Token`)
* Every non-whitelisted endpoint requires the `X-Internal-Token` HTTP request header.
* The header value must match the `INTERNAL_API_TOKEN` configured in the microservice's `.env`.
* If the token is missing or mismatched, the microservice returns `HTTP 401 Unauthorized`.
* Whitelisted endpoints requiring no token: `/health`, `/tester`, `/docs`, `/openapi.json`.

```http
X-Internal-Token: change-me-before-deploying-a-very-long-secret-key
```

### 2.2 Client-Side HTTP Timeout Configuration
* **Never use default HTTP client socket timeouts** (which default to 5 seconds in many libraries).
* Due to GPU model loading and 4-bit vision inference on edge hardware (RTX 2050 4GB), queries may take **2 to 15 seconds** depending on whether model swapping is active.
* Set both **Connection Timeout** and **Read Timeout** to at least **60 seconds** in your Spring Boot `RestClient`, `WebClient`, or `RestTemplate` configurations.

### 2.3 SQL Execution Safety
* The `POST /api/v1/search/nl2sql` endpoint **generates and validates SQL**, but **never executes it**.
* The Java backend is solely responsible for query execution against PostgreSQL.
* Always enforce:
  1. Inspect `safety_check.passed == true` before executing.
  2. Execute the query using a dedicated **read-only database connection / transaction** (`@Transactional(readOnly = true)`).
  3. Validate that `query_type` is `"SELECT"`. If `query_type` is `"UNSUPPORTED"`, reject execution immediately.

## 3. Detailed REST API Contracts

### Endpoint 1: Zero-Trust Visual Extraction & Math Verification

Extracts metadata from scanned FDR documents and executes formulaic compound interest verification.

* **URL**: `/api/v1/fdr/analyze`
* **Method**: `POST`
* **Content-Type**: `multipart/form-data`
* **Supported File Types**: PDF (`.pdf`), JPEG (`.jpg`, `.jpeg`), PNG (`.png`), WebP (`.webp`), TIFF (`.tiff`), BMP (`.bmp`).

#### Request Parameters (Multipart Form-Data)

| Field Name | Type | Required | Description |
|---|---|---|---|
| `file` | Binary File | Yes | Scanned FDR image or single-page PDF document. |
| `document_id` | String | Yes | Unique UUID or business identifier generated by the Java backend (e.g. `FDR-2025-00123`). |
| `requested_by` | String | No | Identity of the user or system triggering the analysis (default: `system`). |

#### Expected Response (`application/json`)

```json
{
  "document_id": "FDR-2025-00123",
  "status": "success",
  "extracted_fields": {
    "issuing_bank": "State Bank of India",
    "branch_name": "New Delhi Main Branch",
    "customer_name": "All India Council for Technical Education",
    "account_number": "30984521789",
    "principal_amount": 500000.00,
    "interest_rate_percent": 6.75,
    "compounding_frequency": "quarterly",
    "date_of_issue": "2024-01-15",
    "date_of_maturity": "2026-01-15",
    "printed_maturity_amount": 572384.50,
    "nominee_name": null
  },
  "math_verification": {
    "is_mathematically_valid": true,
    "check_was_possible": true,
    "expected_maturity_amount": 572612.33,
    "printed_maturity_amount": 572384.50,
    "discrepancy_amount": -227.83,
    "discrepancy_percent": -0.04,
    "tolerance_used_percent": 0.5,
    "flag_reason": null
  },
  "confidence": {
    "overall_score": 0.94,
    "low_confidence_fields": []
  },
  "processing_time_ms": 3410,
  "model_used": "Qwen2.5-VL-3B-Instruct-4bit-NF4"
}
```

#### Interpreting Status & Math Flags in Java

* **`status`**:
  * `"success"`: All critical fields were extracted and the mathematical check completed.
  * `"partial"`: Some critical fields could not be legibly parsed (e.g. illegible date or faded text).
  * `"failed"`: File could not be decoded or vision model yielded no parseable tokens.
* **`check_was_possible`**:
  * If `false`, one or more input variables ($P$, $r$, $t$, printed amount) were absent. **This represents an OCR limitation, not proof of tampering.**
* **`is_mathematically_valid`**:
  * If `false` **AND** `check_was_possible` is `true`, the printed maturity deviates from the compound formula by more than the tolerance threshold (default $\pm 0.5\%$). **This is a primary fraud alert indicating altered deposit figures.**

### Endpoint 2: Visual Forensics (Error Level Analysis)

Analyzes compression anomalies to detect digitally altered dates, copy-pasted text, or forged bank seals.

* **URL**: `/api/v1/fdr/forensics`
* **Method**: `POST`
* **Content-Type**: `multipart/form-data`
* **Supported File Types**: Raster images only (`.jpg`, `.jpeg`, `.png`, `.bmp`, `.webp`). PDFs must be rendered to raster images before calling forensics.

#### Request Parameters (Multipart Form-Data)

| Field Name | Type | Required | Description |
|---|---|---|---|
| `file` | Binary File | Yes | FDR raster image. |
| `document_id` | String | Yes | Unique document tracking identifier. |
| `return_ela_image` | Boolean | No | If `true`, returns base64 PNG of the colorized ELA heatmap (default: `false`). |

#### Expected Response (`application/json`)

```json
{
  "document_id": "FDR-2025-00123",
  "status": "suspicious",
  "tamper_probability_score": 0.724,
  "ela_amplification_factor": 90,
  "flagged_regions": [
    {
      "region_id": 1,
      "bounding_box": [340, 820, 210, 60],
      "anomaly_type": "digital_alteration",
      "confidence": 0.812,
      "description": "High ELA residual detected near text in bottom-left area — consistent with individual digit or date modification."
    },
    {
      "region_id": 2,
      "bounding_box": [45, 52, 175, 170],
      "anomaly_type": "seal_overlay",
      "confidence": 0.745,
      "description": "Bank seal/stamp in top-left area shows inconsistent compression — may be digitally overlaid rather than physically printed."
    }
  ],
  "ela_image_base64": "iVBORw0KGgoAAAANSUhEUgAA...",
  "processing_time_ms": 415
}
```

#### Frontend Bounding Box Math
Coordinates in `bounding_box` are `[x, y, width, height]` in pixel units relative to the original image dimensions.  
To scale these rectangles onto responsive React images:

$$\text{scale}_X = \frac{\text{RenderedWidth}}{\text{IntrinsicWidth}}, \quad \text{scale}_Y = \frac{\text{RenderedHeight}}{\text{IntrinsicHeight}}$$

$$\text{CSS Left} = x \times \text{scale}_X, \quad \text{CSS Top} = y \times \text{scale}_Y$$
$$\text{CSS Width} = \text{width} \times \text{scale}_X, \quad \text{CSS Height} = \text{height} \times \text{scale}_Y$$

### Endpoint 3: NL2SQL Administrative Copilot

Converts natural language institutional queries into strictly safe PostgreSQL `SELECT` queries.

* **URL**: `/api/v1/search/nl2sql`
* **Method**: `POST`
* **Content-Type**: `application/json`

#### Request Body (`application/json`)

```json
{
  "query": "Show me all FDRs expiring within the next 30 days in West Bengal",
  "schema_context": "CREATE TABLE fdrs (id UUID PRIMARY KEY, bank_name TEXT, state TEXT, principal NUMERIC, maturity_date DATE, status TEXT);",
  "max_rows_hint": 50
}
```

#### Expected Response (`application/json`)

```json
{
  "original_query": "Show me all FDRs expiring within the next 30 days in West Bengal",
  "generated_sql": "SELECT id, bank_name, principal, maturity_date, status FROM fdrs WHERE state = 'West Bengal' AND maturity_date BETWEEN CURRENT_DATE AND CURRENT_DATE + INTERVAL '30 days' AND status = 'active' ORDER BY maturity_date ASC LIMIT 50;",
  "query_type": "SELECT",
  "explanation": "Retrieves active FDRs in West Bengal maturing within the next 30 days, sorted by earliest maturity date, capped at 50 records.",
  "safety_check": {
    "is_read_only": true,
    "contains_insert": false,
    "contains_update": false,
    "contains_delete": false,
    "contains_drop": false,
    "contains_truncate": false,
    "contains_alter": false,
    "contains_create": false,
    "contains_grant": false,
    "contains_execute": false,
    "passed": true
  },
  "model_used": "llama3.2",
  "processing_time_ms": 1820
}
```

#### Security Rejection (`HTTP 422 Unprocessable Entity`)
If the model produces any statement containing modification keywords or non-SELECT operations, the endpoint aborts execution and returns:

```json
{
  "detail": {
    "error": "Generated SQL failed safety check — non-SELECT statement detected.",
    "safety_check": {
      "is_read_only": false,
      "contains_drop": true,
      "passed": false
    },
    "raw_sql": "DROP TABLE fdrs;"
  }
}
```

## 4. HTTP Status Codes & Error Formats

| Status Code | Meaning | Cause | Action Required |
|---|---|---|---|
| `200 OK` | Success | Processing completed. | Parse response JSON. |
| `400 Bad Request` | Client Error | Empty file or blank parameter. | Verify multipart form-data fields. |
| `401 Unauthorized` | Auth Error | Missing or invalid `X-Internal-Token`. | Verify shared secret in request header. |
| `415 Unsupported Media` | Format Error | PDF submitted to forensics endpoint. | Render PDF page to JPEG/PNG first. |
| `422 Unprocessable` | Security Rejection | Prompt injection or non-SELECT SQL. | Display rejection warning to admin user. |
| `500 Server Error` | Pipeline Error | Uncaught exception in AI inference. | Inspect Uvicorn terminal logs. |
| `503 Unavailable` | Dependency Down | Ollama daemon is unreachable. | Ensure `ollama serve` is running. |

## 5. Sample Spring Boot Integration Client

Below is a reference implementation using Spring Framework 6.x `RestClient`:

```java
package in.gov.aicte.pramaan.client;

import org.springframework.beans.factory.annotation.Value;
import org.springframework.core.io.ByteArrayResource;
import org.springframework.http.MediaType;
import org.springframework.http.client.SimpleClientHttpRequestFactory;
import org.springframework.stereotype.Service;
import org.springframework.util.LinkedMultiValueMap;
import org.springframework.util.MultiValueMap;
import org.springframework.web.client.RestClient;

import java.time.Duration;
import java.util.Map;

@Service
public class AiServiceClient {

    private final RestClient restClient;
    private final String internalToken;

    public AiServiceClient(
            @Value("${ai.service.url:http://localhost:8000}") String baseUrl,
            @Value("${ai.service.token}") String internalToken) {
        
        this.internalToken = internalToken;

        // Configure 60-second timeouts to accommodate GPU swapping
        SimpleClientHttpRequestFactory factory = new SimpleClientHttpRequestFactory();
        factory.setConnectTimeout((int) Duration.ofSeconds(10).toMillis());
        factory.setReadTimeout((int) Duration.ofSeconds(60).toMillis());

        this.restClient = RestClient.builder()
                .baseUrl(baseUrl)
                .requestFactory(factory)
                .defaultHeader("X-Internal-Token", internalToken)
                .build();
    }

    /**
     * Pipeline A: Analyze FDR Document
     */
    public Map<String, Object> analyzeFdr(byte[] fileBytes, String filename, String documentId) {
        MultiValueMap<String, Object> body = new LinkedMultiValueMap<>();
        body.add("file", new ByteArrayResource(fileBytes) {
            @Override
            public String getFilename() {
                return filename;
            }
        });
        body.add("document_id", documentId);
        body.add("requested_by", "spring-backend");

        return restClient.post()
                .uri("/api/v1/fdr/analyze")
                .contentType(MediaType.MULTIPART_FORM_DATA)
                .body(body)
                .retrieve()
                .body(Map.class);
    }

    /**
     * Pipeline B: Run ELA Forensics
     */
    public Map<String, Object> runForensics(byte[] imageBytes, String filename, String documentId) {
        MultiValueMap<String, Object> body = new LinkedMultiValueMap<>();
        body.add("file", new ByteArrayResource(imageBytes) {
            @Override
            public String getFilename() {
                return filename;
            }
        });
        body.add("document_id", documentId);
        body.add("return_ela_image", "true");

        return restClient.post()
                .uri("/api/v1/fdr/forensics")
                .contentType(MediaType.MULTIPART_FORM_DATA)
                .body(body)
                .retrieve()
                .body(Map.class);
    }

    /**
     * Pipeline C: Translate Natural Language to SQL
     */
    public Map<String, Object> translateToSql(String query, String schemaDdl, int maxRows) {
        Map<String, Object> request = Map.of(
                "query", query,
                "schema_context", schemaDdl,
                "max_rows_hint", maxRows
        );

        return restClient.post()
                .uri("/api/v1/search/nl2sql")
                .contentType(MediaType.APPLICATION_JSON)
                .body(request)
                .retrieve()
                .body(Map.class);
    }
}
```
